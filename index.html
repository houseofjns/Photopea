Welcome to Photopea

A practical beginner course for confident image editing.

What is Photopea?

Photopea is a browser-based image editor. It supports common image formats and PSD files. Photopea ကို browser ထဲကနေ အသုံးပြုနိုင်တဲ့ image editing software တစ်ခုဖြစ်ပါတယ်။

Before you begin

Use a computer, mouse and stable internet. Visit photopea.com. Create a folder named Photopea_Basic_StudentName.

သတိပြုရန် — မူရင်းဓာတ်ပုံကို မဖျက်ပါနှင့်။ အမြဲတမ်း copy တစ်ခုဖန်တီးပြီး PSD နှင့် JPG/PNG နှစ်မျိုးလုံး သိမ်းပါ။

Course outcomes

  • Understand workspace, layers, selections and text.
  • Crop, resize, remove backgrounds and retouch photos.
  • Design posters, social media graphics and product advertisements.
  • Export clean files for web and print.

DOCUMENT SIZE GUIDE

Canvas Size ကို Inches ဖြင့်သတ်မှတ်နည်း

Photopea မှာ New Document ဖန်တီးတဲ့အခါ Width / Height unit ကို Inches ရွေးပြီး အရွယ်အစားသတ်မှတ်နိုင်ပါတယ်။

အရေးကြီးချက် — Inches အရွယ်အစားတစ်ခုတည်းနဲ့ pixel အရေအတွက်ကို မသတ်မှတ်နိုင်ပါ။ Resolution (DPI/PPI) ပေါ်မူတည်ပါတယ်။ ဒီသင်တန်း Project များအတွက် အောက်ပါ inch + 300 DPI setting ကိုသုံးပါ။
  1. File → New ကိုနှိပ်ပါ။
  2. New Document window ထဲက Width / Height ဘေးရှိ unit dropdown ကို inches (in) ရွေးပါ။
  3. Resolution ကို 300 Pixels/Inch ထားပါ။
  4. Width နဲ့ Height ကို Project Guide မှာပြထားတဲ့ inches အတိုင်းထည့်ပါ။
  5. Create ကိုနှိပ်ပါ။ Pixel dimensions ကိုလည်း အလိုအလျောက်တွက်ပေးပါလိမ့်မယ်။

Real-World Final Portfolio

Complete these five projects by the end of the course.

01 · Mini Mart Promotion

Design a 3.6 × 4.5 inches (1080 × 1350 px @ 300 DPI) grocery promotion poster with product images, price tags and contact details.

Skills: layers, shapes, text, alignment.

02 · Training Center Social Post

Create a course-enrolment post for House of J&S. Include course name, benefits, date and call-to-action.

Skills: typography, hierarchy, colour.

03 · Product Advertisement

Make a clean product ad with cut-out product, soft shadow, headline and offer badge.

Skills: selection, mask, transform.

04 · Portrait Enhancement

Improve brightness and colour naturally. Keep the person's identity and natural features unchanged.

Skills: adjustment layers, retouching.

05 · Event / Birthday Poster

Build a polished event poster with a clear focal image, date, venue and decorative shapes.

Skills: composition, effects, export.
